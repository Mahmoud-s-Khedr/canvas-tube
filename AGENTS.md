# CanvasTube Agent Instructions

## Feature implementation references

When asked to implement a CanvasTube feature, first consult the relevant local codebases in `References-project/` to learn established implementation patterns, APIs, architecture, and edge cases before designing the change.

- Use `docs/REFERENCES.md` to choose the relevant reference project.
- Treat all contents of `References-project/` as learning material and architectural reference only; do not copy source code into CanvasTube.
- Preserve each reference project's licensing boundaries. In particular, never add `@tldraw/tldraw` as a CanvasTube dependency or import its source.
- `References-project/` is local-only and ignored by Git; do not add its contents to commits.
